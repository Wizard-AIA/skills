# 🧙‍♂️ Wizard Skills

A community registry of `SKILL.md` files for **[Wizard](https://github.com/Wizard-AIA/Wizard-w2)** — curated analytical know-how and statistical guidelines that the agent retrieves, cites, and consults mid-analysis.

[![Validate Skills](https://github.com/Wizard-AIA/skills/actions/workflows/validate.yml/badge.svg)](https://github.com/Wizard-AIA/skills/actions/workflows/validate.yml) [![License](https://img.shields.io/badge/License-BSD_3--Clause-blue.svg)](LICENSE)

## ⚡ Quick Install

Install all or selected skills from this registry directly via the `wizard` CLI:

```bash
# Using the prebuilt wizard CLI:
./cli/wizard skills add Wizard-AIA/skills

# Or from source / Python environment:
python backend/main.py skills add Wizard-AIA/skills
```

This walks through every skill in the repository and prompts for confirmation before installing — pass `--yes` to install all without prompting.

## 🔍 What a Skill Is

A `SKILL.md` file combines restricted YAML frontmatter with Markdown guidance:

```markdown
---
name: outlier-detection
description: Choosing a detection method that matches the data's actual distribution
tags: [outliers, anomaly-detection, statistics]
version: 1.0
---

## When to use this
...
```

The frontmatter is parsed by a **strictly restricted YAML parser** (`key: value`, quoted strings, and string lists). Anchors, aliases, and custom types are prohibited.

---

## 🛡️ The Hard Rule: No Executable Code

A skill directory **must not contain executable code** (`.py`, `.sh`, `.exe`, `.dll`, `.so`, etc.). 

- Python blocks inside the Markdown are illustrative guidance for the LLM agent.
- Code generated by Wizard during analysis runs inside OS-contained sandboxes.
- A skill file itself is never executed directly.

## 🤝 Submitting a New Skill

1. Fork this repository.
2. Create a new directory under `skills/<your-skill-name>/`.
3. Add your `SKILL.md` following the [Outlier Detection Example](examples/outlier-detection/SKILL.md).
4. Run local validation:
   ```bash
   python3 .github/scripts/validate_skills.py
   python3 .github/scripts/build_registry.py
   ```
5. Open a Pull Request!
